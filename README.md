# Архив обучения FILMMAKER 2.0

25 сохранённых страниц курса с навигацией. Главная страница оформлена по брендбуку NeuroMilanka. Уроки сохраняют исходное оформление.

В верхней панели: предыдущий и следующий урок, возврат к каталогу, встроенный плеер Google Drive, ссылки на скачивание и папка урока. 18 видео и 46 материалов остаются на Google Диске. PDF-копии страниц исключены; памятка ученика сохранена в ссылках. Папка Google Диска открыта всем, у кого есть ссылка, для просмотра и скачивания.

Личные ответы и скрипты учебного аккаунта удалены.
