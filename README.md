# FILMMAKER 2.0

Личный каталог 25 сохранённых страниц курса. Откройте `index.html`. В каждом уроке есть возврат к каталогу и переходы к соседним урокам.

Личные ответы, формы и скрипты учебного аккаунта удалены. Видео и внешние вложения могут требовать авторизации на сайте курса. Исходные MHTML остаются в исходной папке.
